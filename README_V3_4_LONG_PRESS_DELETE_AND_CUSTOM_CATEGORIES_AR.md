# Budget Home V3.4 — حذف الإدخال بالضغط المطوّل + أنواع مصروفات مخصصة

## ما الذي تغير؟

1. حذف الإدخال المالي صار مثل واتساب:
   - اضغط ضغطًا مطوّلًا على فقاعة المصروف أو الدخل.
   - يظهر تأكيد حذف.
   - عند الحذف يتم حذف العملية من سجل الحسابات، وليس مجرد مسح رسالة.

2. أثر الحذف يرجع إلى الميزانية:
   - إجمالي المصروفات يقل.
   - المتبقي في الميزانية يزيد.
   - حدود التصنيفات تتحدث.
   - تقارير الشات لا تحتسب العملية المحذوفة.

3. إصلاح احتساب حدود المصروفات:
   - تم جعل مطابقة التصنيفات أكثر مرونة عربيًا، مثل: إيجار / ايجار.
   - عند تحديد حد لتصنيف بعد تسجيل مصروفات سابقة، يحسب المصروفات السابقة فورًا.

4. إضافة نوع مصروف جديد:
   - من الإعدادات يمكن الضغط على زر + بجوار “أنواع وحدود المصروفات الشهرية”.
   - اكتب اسم النوع والحد الشهري الاختياري.
   - بعد ذلك إذا ظهر اسم النوع في رسالة الشات، يتم ربط المصروف به.

## ملاحظات مهمة

- الإشعارات الحالية داخلية ومحلية فقط.
- إشعار مثل واتساب على موبايل الزوجة يحتاج Firebase Cloud Messaging لاحقًا.
- صورة الحساب ما زالت محلية حتى ربط Firebase Storage لاحقًا.
