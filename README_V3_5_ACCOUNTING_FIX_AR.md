# Budget Home V3.5 — إصلاح الحسابات والحدود والتقارير

هذه النسخة تركّز على قلب التطبيق المالي قبل إضافة ميزات جديدة.

## ما تم إصلاحه

1. **الحدود الشهرية أصبحت شهرية فعلًا**
   - صفحة الإعدادات تعرض مصروف الشهر الحالي فقط أمام كل حد.
   - إذا تم وضع حد للإيجار ثم تم تسجيل مصروف إيجار، يظهر: الحد / المصروف هذا الشهر / المتبقي أو التجاوز.

2. **توحيد أسماء التصنيفات**
   - `إيجار` و `ايجار` و `الإيجار` يتم التعامل معها كتصنيف واحد.
   - اختلافات الهمزات والتاء المربوطة لا تكسر الحساب.

3. **أنواع المصروفات الجديدة**
   - إذا أضفت نوعًا جديدًا مثل `مصروف محمد` وحددت له حدًا، ثم كتبت في الشات `دفعت 100 لمحمد`، يتم ربط المصروف بهذا النوع وخصمه من الحد.
   - إذا أضفت نوعًا مثل `فراخ` ثم كتبت `اشتريت فراخ 300`، يتم الخصم من حد `فراخ` إذا كان له حد.

4. **التقارير داخل الشات**
   - التقرير يجمع التصنيفات بنفس منطق الإعدادات.
   - التقرير يضيف حدود الميزانية لهذا الشهر تلقائيًا عندما توجد حدود.

5. **التقارير العامة**
   - شاشة التقارير أصبحت تعرض بيانات الشهر الحالي حتى لا تختلط مصروفات قديمة مع حدود شهرية.

## ملاحظات مهمة

- حذف الإدخال المالي يتم بالضغط المطول على فقاعة المصروف، وليس مسح الشات.
- الإشعارات بين أجهزة العائلة ما زالت تحتاج Firebase Cloud Messaging في المرحلة القادمة.
- عروض الشراء مثل عروض الفراخ يمكن إضافتها لاحقًا كميزة Smart Shopping، لكنها لا يجب أن تسبق تثبيت الحسابات والتقارير.
