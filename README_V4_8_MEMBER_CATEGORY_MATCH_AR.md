# Budget Home V4.8 — Member/Category Hard Match

هدف النسخة: حل حالة مثل:

- نوع/حد في الإعدادات باسم: محمد، الحد 1000
- رسالة في الشات: انا اديت محمد 500 من مصاريفه

التعديل:
- يطابق أسماء الميزانيات والفئات المخصصة وأسماء أفراد العائلة قبل التصنيفات العامة.
- عبارات: محمد / مصروف محمد / مصاريف محمد / حساب محمد يتم التعامل معها كمرادفات.
- كلمات مثل: اديت / اعطيت تعتبر مصروف.
- عند حفظ المصروف، يجب أن تظهر رسالة التأكيد بتصنيف محمد وليس أخرى.

اختبارات منطق المطابقة قبل التسليم:
- انا اديت محمد 500 من مصاريفه + محمد => match
- انا اديت محمد 500 من مصاريفه + مصروف محمد => match
- دفعت 100 جنيه لمحمد من مصروفه + محمد => match
- اشتريت فراخ 350 + فراخ => match
