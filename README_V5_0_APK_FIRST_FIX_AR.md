# Budget Home V5.0 — APK-first Invite, Voice, and Share Fix

هذه النسخة تركز على تجربة APK بدل الويب:

- تعطيل Android Auto Backup حتى لا تعود بيانات قديمة بعد إعادة التثبيت.
- لو التطبيق فُتح من دعوة `budgethome://join?...` يتم تجاهل الجلسة القديمة ويذهب لشاشة الانضمام.
- اختيار أفضل لغة عربية متاحة للمايك بدل الاعتماد على اللغة الافتراضية للجهاز.
- إضافة زر "مشاركة التطبيق" في أعلى الشات لكل أعضاء العائلة، لمشاركة رابط التثبيت/التجربة مع أي شخص خارج العائلة.
- استمرار رابط دعوة العضو المخصص من صفحة `install.html`.

ملاحظة: لا يمكن لأي رابط تثبيت APK تلقائيًا بدون فتح المتصفح/صفحة التحميل، لأن Android يمنع التثبيت الصامت لأسباب أمنية. المطلوب في التجربة: تحميل APK ثم فتح الدعوة في التطبيق.
