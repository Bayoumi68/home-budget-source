# V4.2 Accounting Web Fix

هذه النسخة تصلح قلب الحسابات بعد نشر نسخة الويب:

- إعادة حساب الحدود الشهرية من سجل المصروفات الحقيقي عند فتح صفحة الإعدادات.
- حساب المصروف حسب الشهر الحالي فقط.
- مطابقة التصنيفات العربية بمرونة: إيجار/ايجار/الإيجار.
- دعم الأنواع الجديدة: إذا أضفت "فراخ" أو "مصروف محمد" ثم سجلت مصروفًا يحمل نفس الاسم، يتم خصمه من هذا النوع.
- عند إضافة/حذف مصروف يتم إعادة حساب حدود الميزانية في Firestore.
- التقارير تستخدم نفس منطق التصنيفات والحدود.

ملاحظة: إذا كانت لديك بيانات قديمة متسجلة قبل الإصلاح، افتح صفحة الإعدادات بعد النشر لتجبر التطبيق على إعادة الحساب.
