# Budget Home V4.3 — إصلاح رابط الدعوة ومطابقة الحسابات

## ما تم إصلاحه

1. رسالة الدعوة لم تعد تستخدم رابط Google Play الوهمي.
2. رسالة الدعوة تستخدم رابط الويب الحقيقي: https://budget-home-family-test.web.app
3. رابط الدعوة يضم كود الدعوة كـ query parameter: ?invite=CODE
4. تحسين مطابقة التصنيفات العربية، خاصة:
   - لمحمد -> محمد
   - مصروفه -> مصروف
   - الإيجار/ايجار/إيجار
5. عند إضافة نوع مثل "مصروف محمد" أو "محمد" ثم تسجيل "دفعت 100 لمحمد من مصروفه"، يجب ربط المصروف بهذا النوع بدل أخرى.
6. صفحة الإعدادات أصبحت بها زر إعادة حساب الحدود.
7. التقرير والإعدادات يستخدمان نفس منطق المطابقة.

## اختبار سريع

1. افتح الإعدادات.
2. أضف نوع جديد: محمد أو مصروف محمد.
3. ضع الحد: 1000.
4. في الشات اكتب: دفعت 100 جنيه لمحمد من مصروفه.
5. ارجع للإعدادات أو اضغط زر التحديث.
6. المفروض يظهر صرف 100 والمتبقي 900.
