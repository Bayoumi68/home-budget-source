# Budget Home V3.2 — Chat Product Upgrade

هذه النسخة تضيف تحسينات تجربة الشات العائلية قبل الانتقال إلى Firebase:

- زر مسح الشات مع الحفاظ على المصاريف والمعاملات.
- التقارير داخل الشات مقسمة إلى 5 سطور لكل صفحة، مع زر/أمر "التالي".
- أوامر الميزانية مثل "ميزانية الشهر" تعرض تقريرًا حقيقيًا وليس مجرد تكرار الكلام.
- رفع صورة حساب محلية من المعرض.
- أمثلة المصروفات لا تسجل مباشرة؛ تضع النص في مربع الكتابة ثم الإرسال بالسهم.
- إشعارات داخلية للعائلة عند تسجيل مصروف/دخل، كتجربة محلية مؤقتة قبل Firebase Cloud Messaging.

ملاحظة مهمة: الإشعارات والصور حاليًا محلية على الجهاز. في نسخة Firebase ستتم مزامنتها بين أجهزة العائلة.
