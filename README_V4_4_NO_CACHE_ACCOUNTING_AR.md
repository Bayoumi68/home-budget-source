# Budget Home V4.4 — No Cache + Accounting Fix

هذه النسخة تضيف:

- تعطيل كاش Firebase Hosting عبر headers في `firebase.json`.
- يجب البناء بالأمر: `flutter build web --release --pwa-strategy=none` لتجنب ظهور نسخة قديمة من المتصفح.
- رسالة الدعوة تستخدم رابط الويب الحقيقي وليس Google Play.
- تحسين ربط مصروفات الأطفال: "دفعت 100 لمحمد من مصروفه" يمكن أن يطابق "محمد" أو "مصروف محمد" أو "حساب محمد".
- شاشة الإعدادات تقرأ الأنواع من الأنواع المحفوظة + حدود الميزانية نفسها حتى لو كانت من نسخة قديمة.

اختبار سريع:
1. افتح الإعدادات وأضف نوع: محمد، الحد: 1000.
2. في الشات اكتب: دفعت 100 جنيه لمحمد من مصروفه.
3. ارجع الإعدادات واضغط تحديث.
4. المتوقع: محمد — المصروف 100 — المتبقي 900.
